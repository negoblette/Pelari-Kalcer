# Fitur yang di-hold

File di folder ini tidak dipakai halaman mana pun. Folder berawalan `_` tidak menjadi route.

- `landing/`: Fit Check, kalkulator pace, rute, pembuat bib, dan halaman depan lama.
- `dashboard/`: dashboard tracker lama, termasuk target bulanan, grafik mingguan, tren pace, rekor, dan riwayat.
